
# Portfolio Demo Plan

## Goal

Demonstrate MacroSignal in 8–12 minutes.

## Demo Story

1. Open the Macro Snapshot.
2. Show one historical date.
3. Display the macro values **as they were known then**.
4. Compare with today's revised values to demonstrate why ALFRED matters.
5. Show the release calendar and one expectation/forecast.
6. Show the corresponding surprise / forecast error.
7. Show filtered regime probabilities.
8. Show cross-asset event response.
9. Show the signal and portfolio weights.
10. Open the audit trail proving all inputs were available before the decision.
11. Show walk-forward performance vs simple baselines.
12. Show an ablation where regime or surprise is removed.
