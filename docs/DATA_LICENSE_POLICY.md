
# Data License & Usage Policy

## Principles

- Respect source terms and redistribution restrictions.
- Do not commit raw licensed data to GitHub.
- Do not scrape protected consensus datasets.
- Store user/institution-specific data outside the repository.
- Use small synthetic or permitted fixtures for tests.

## Consensus Data

The repository provides an import schema, not redistributed proprietary
consensus history.

## Market Data

The demo provider is replaceable.

Do not imply a convenience/free provider is suitable for institutional live
trading.

## Official Sources

Cache only as permitted and keep source attribution in metadata.
