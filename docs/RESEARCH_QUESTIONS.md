
# Research Questions

## Primary

Can point-in-time macro information and pre-release expectation errors identify
economically interpretable states and improve out-of-sample cross-asset
allocation?

## Secondary

1. Are macro-surprise responses stable across regimes?
2. Does the yield-curve state add information beyond macro levels?
3. Do HMM/GMM regimes outperform transparent rule-based regimes out of sample?
4. Does adding surprise information improve a regime-only strategy?
5. Does adding a regime layer improve a surprise-only strategy?
6. Are gains robust to transaction costs and alternative execution lags?
7. Are results concentrated in one crisis or asset?
8. How different are historical conclusions when revised data are used instead
   of real-time vintages?

## Explicit Null Possibility

The project must allow the answer:

> No robust allocation improvement was found after proper point-in-time controls.

That is a valid research result.
